# Data

## UIUC Propeller Data Site

The validation reference for Level 2A. Download from the UIUC Applied
Aerodynamics Group and unpack here as `UIUC-propDB/`.

Not committed: third-party data, roughly 90 MB.

A propeller is only a candidate for the thrust stand if this database already
holds data for it. Without that there is nothing independent to validate against.
